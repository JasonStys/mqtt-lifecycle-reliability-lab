# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch. This demonstration project does not
maintain older release lines.

## Report privately

Use GitHub's private security-advisory feature for this repository. Include the affected commit,
reproduction steps, impact, and any suggested mitigation. Please do not publish credentials,
personal data, or exploit details in a public issue.

The local Mosquitto profile is intentionally anonymous and loopback-only. Exposing it outside the
local machine is unsupported and should not be reported as a vulnerability.
